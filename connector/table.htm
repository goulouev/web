S-Data Import
1. Copy your s-data from a text editor (NotePad, WordPad, etc.) into clipboard (Right Mouse Click, Select All, Copy).
2. Paste the s-data into the text window (Right Mouse Click, Paste).
3. Select appropriate data format
4. Click the "Import" button

S-Data Export
1. Click the "Export" button.
2. Paste the s-data into a text editor (Right Mouse Click, Paste).
3. Save the table as a text file.
